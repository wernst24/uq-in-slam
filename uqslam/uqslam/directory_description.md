# Directory Description: 

This directory currently serves as a catch-all workspace for rapid development and experimentation. It contains a mixture of:
- Agent definitions (e.g., `random_agent.py`, `Project_Det_*.py`)
- Training scripts and evaluation pipelines
- Neural network model definitions (e.g., `Network_Model_Det_*.py`)
- Environment wrappers, controllers, and plotting tools

This unstructured layout reflects the exploratory phase of the project. As development matures, components from this directory may be refactored into more modular locations (e.g., agents/, training/, models/, utils/, etc.) with clearer separation of concerns and documentation.
